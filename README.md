# uz-hunspell
Oʻzbek tilidagi matnlarda imlo xatolarini tekshirish uchun Hunspell lugʻatlari (Uzbek Hunspell dictionary)

Lugʻatda oʻzbek tilidagi 90 000 dan oshiq soʻz va OT, SIFAT, FE'L soʻz turkumlari uchun qoʻshimchalar berilgan.

`uz_UZ` — joriy lotin alifbosi (sh, ch, oʻ, gʻ), `uz_UZ_Cyrl` — kirill alifbosi, `uz_UZ_2026` — 2026-yilda tasdiqlangan yangi lotin alifbosi (Sh→Ş, Ch→Ç, Oʻ→Ö, Gʻ→Ğ). `uz_UZ_2026` fayllari `uz_UZ`dan `scripts/convert_2026.py` skripti bilan avtomatik hosil qilinadi.

Linux tizimida oʻrnatish usuli:

```bash
sudo bash ./install.sh
```
